# Тень над Холлоу-Корт

Камерный английский детектив. Интерактивная текстовая игра. Главы 1–2.

## О игре

«Тень над Холлоу-Корт» — текстовый детектив с выборами, где каждое решение имеет последствия. Вы — мисс Элинор Вейл, стенографистка и частный следователь, прибывшая в английский особняк после смерти леди Миртл Эшфорд. За два дня вам нужно раскрыть правду — или стать ещё одной жертвой.

### Персонажи

- **Вера Линд** — 39 лет, компаньонка леди Миртл

### Особенности
- **2 главы**, ~30–45 минут прохождения
- **3 смертельных узла** — можно погибнуть, если не собрать улики
- **Система интуиции** — 2 попытки переиграть фатальную сцену
- **Дневник** — собирайте улики и фильтруйте их
- **Сводка дела** — систематизируйте знания
- **2 концовки** — раскрытие или ошибка
- **Тёмная и светлая тема**
- **Адаптивная вёрстка** — от 320px до 2560px

## Как запустить локально

### Вариант 1: Просто открыть файл
Откройте `dist/index.html` в браузере. Всё работает локально.

### Вариант 2: Через сервер разработки
```bash
npm install
npm run dev
```
Откройте http://localhost:5173

### Вариант 3: Сборка и preview
```bash
npm run build
npx serve dist
```

## Как собрать zip для itch.io

1. Выполните сборку:
   ```bash
   npm run build
   ```

2. Создайте zip-архив из папки `dist/`:
   ```bash
   cd dist
   zip -r ../hollow-court-itchio.zip .
   ```

3. Загрузите `hollow-court-itchio.zip` на itch.io как HTML5 проект.

## Как играть

1. **Титульный экран**: Нажмите «Начать» для новой игры или «Продолжить» для загрузки сохранения.
2. **Чтение**: Текст появляется по блокам. Читайте внимательно — ключевые детали не выделяются.
3. **Выборы**: В некоторых сценах нужно выбрать вариант ответа. В многозначных выборах — выберите нужное количество и нажмите «Подтвердить».
4. **Дневник**: Кнопка в правом верхнем углу. Показывает собранные улики.
5. **Сводка**: Кнопка в правом верхнем углу. Систематизирует ваши знания.
6. **Смерть**: Если вы погибли — можно переиграть сцену (если есть интуиция) или начать заново.
7. **Настройки**: Тема, размер шрифта, анимации.

## Механики

### Интуиция
- 2 единицы на главу
- Тратится при смерти для возврата к началу сцены
- Не работает в финальных сценах (2.7, 2.8)
- При 0 — смерть необратима

### Улики
- Собираются автоматически при чтении
- Типы: факт, психология, ложь
- Фильтр по типу открывается после первой смерти

### Сохранения
- Автосейв при входе в каждую сцену
- Хранится в localStorage (ключ: `hollow_court_save_v1`)
- Очистка данных браузера удалит сохранения
